# 整页一键翻译

一个 Manifest V3 Chrome 扩展。点一下，把当前网页变成**双语对照**：英文原文留在原处，中文译文插在每个段落或标题下面。再点一次，译文全部移除。

它对接 DeepSeek 的 OpenAI 兼容接口，并尽量不把技术词译歪。Claude 还是 Claude，Agent 不会变成「代理」或「克劳德」。

## 安装

1. 打开 `chrome://extensions`。
2. 打开右上角「开发者模式」。
3. 点「加载已解压的扩展程序」，选择本仓库根目录（里面有 `manifest.json` 的那一层）。
4. 把扩展固定到工具栏。

更新代码后，在扩展卡片上点刷新。

## 配置 API Key

右键工具栏图标，选「选项」。

| 项 | 默认 |
| --- | --- |
| API Key | 空。没有 Key 时会提示去设置页填写 |
| 模型 | `deepseek-chat` |
| Base URL | `https://api.deepseek.com` |
| 目标语言 | 简体中文 |

Key、模型和地址都存在 `chrome.storage.local`，只留在本机。点「保存并测试连接」会用一句带 Claude、Agent 的话打一次接口，方便确认 Key 和术语保护是否生效。

如果接口前面还有一层兼容网关，把 Base URL 改成网关地址即可。末尾的 `/` 可以省略；填到 `/v1` 也可以，扩展会请求 `{Base URL}/chat/completions`。

## 怎么翻译

三种入口共用同一状态：

- 工具栏图标
- 快捷键 `Alt+Shift+T`（可在 `chrome://extensions/shortcuts` 里改）
- 页面右侧的悬浮按钮

第一次进入「双语对照」。原文不动，译文出现在段落、标题、列表项下方，颜色更浅，左侧有一条粉色竖线。工具栏图标会显示「译」。

再点一次，无论从哪个入口点，都会移除全部译文，图标角标清空。

长页面会按段落分批请求，同时最多 3 批。页面顶部和悬浮按钮都会显示进度，例如「正在翻译 8/36」。

## 悬浮按钮

- 约 50px 的圆，颜色 `#C8607A`，默认一半露在页面右边缘外面，后面接着深灰圆角胶囊。
- 鼠标悬停、键盘聚焦，或正在翻译时，按钮会完整滑进页面，胶囊上显示当前动作。
- 按住上下拖动可以换位置，松手后记在本机。拖动不会误触发翻译。
- 译完后圆底变成白色、图标变成粉色，和「尚未翻译」区分开。
- 设置页可以关掉它。关掉之后，工具栏和快捷键仍可用。
- 「这些网站不显示按钮」每行一个域名。`example.com` 会连同子域名一起隐藏。

按钮和译文都放在 Shadow DOM 里，避免和网页自己的 CSS 缠在一起。

## 术语保护

内置词表覆盖常见 IT / AI 用词，至少包括：Claude、GPT、DeepSeek、Agent、Prompt、Token、LLM、RAG、MCP、Embedding、Fine-tuning、Kubernetes、Docker、API、SDK、CLI、GitHub、Copilot、Cursor、Transformer、Context window，以及一批模型名、产品名和缩写。

翻译时做两件事：

1. **提示词约束**：要求模型保留这些英文，并明确禁止把 Claude 译成「克劳德」、把 Agent 译成「代理」。
2. **占位符**：送翻前把白名单里的词换成 `⟪ab12T0⟫` 这种标记，译文回来后再换回页面上原来的大小写。行内 `code` 同样用占位符保住，不送去翻译。若模型把占位符弄丢，还会按常见误译（克劳德、智能体、令牌等）把丢掉的那几个词改回来。

设置页可以添加、删除术语，或一键恢复内置列表。改完要点保存。匹配按整词，并优先匹配更长的说法，所以 `JavaScript` 不会被拆成 `Java`，`GitHub Copilot` 也不会被拆成两个词。

`code`、`pre`、`script`、`style`、`textarea`、`input` 不会当作正文送翻。代码块保持原样，下面也不会多出一条译文。

## 演示模式

没有 Key 时，可以在设置里打开「演示模式」。它不访问网络，但会走同一套分批、占位符和还原逻辑，方便先看双语排版。

也可以不装扩展，直接预览示例技术文：

```bash
npm install
npm run demo
```

浏览器打开 [http://127.0.0.1:47231/preview](http://127.0.0.1:47231/preview)。这是一篇自写的 Claude / Kubernetes 短文，不是官网页面。点右侧圆按钮即可。

## 开发与测试

```bash
npm install
npm test
```

单元测试覆盖：

- 术语占位、长词优先、译后还原、占位符被改写或丢失时的修正
- 长文分批、占位符不被从中切断、并发上限
- 跳过 `pre` / `script` / `textarea` / 隐藏节点
- 译文插入后原文还在，清除后页面回到原样
- 缺 Key、401、429、网络失败时的中文错误

`npm run e2e` 会打开示例页，检查双语位置、术语、代码块、拖动和悬停，并加载扩展走一遍「演示模式 → 翻译 → 角标 → 还原」。官方 Chrome 137 起不再接受命令行 `--load-extension`，扩展这段需要 Chrome for Testing。脚本会优先用 `CHROME_PATH`，否则在本机已安装的 Chrome for Testing 里找。

## 已知限制

- 只处理顶层页面，不翻译跨域 iframe 里的文档。
- 不翻译 `canvas`、PDF、图片里的字，也跳过 `contenteditable` 编辑器。
- 动态加载出来的新段落不会自动补译，需要还原后再翻一次。
- 译文插在块级元素内部。普通段落、标题、列表没问题；如果某个容器是不换行的 flex，个别译文可能和原文挤在一行。
- 已经大部分是中文的段落不会再送去翻译。
- 占位符丢失时的误译修正只处理本段里没还回来的术语，并且从后往前替换。同一句里如果本来就有「代理」，又恰好把 Agent 的占位符弄丢了，有可能改到正常的「代理」。
- 词表按不区分大小写的整词匹配。页面上小写的 `cursor` 也会被留下来。不需要的词可以在设置里删掉。
- `chrome://` 等浏览器内部页无法注入。
- 演示模式的译文来自内置例句和简单替换，不是模型翻译。
